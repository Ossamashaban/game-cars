## 🚀 How to Play

### Quick Start
1. Open `racing-game.html` in your browser
2. Select your favorite car
3. Choose difficulty level
4. Click "START GAME"

### Controls
| Control | Action |
|---------|--------|
| ⬆️ Arrow Up / W | Accelerate |
| ⬇️ Arrow Down / S | Brake |
| ⬅️ Arrow Left / A | Steer Left |
| ➡️ Arrow Right / D | Steer Right |
| Shift | Nitro Boost |
| Space | Pause/Resume |
| N | Toggle Weather |
| Swipe | Mobile steering |

### Gameplay Tips
- 🚗 Avoid traffic cars to keep your health
- 💰 Collect coins for bonus points
- ⚡ Use nitro strategically
- 🌧️ Master weather effects
- 🏆 Beat your high score!

## 🎨 Customization

You can customize the game by editing values in `racing-game.html`:

```javascript
// Game constants
const MAX_SPEED = 20;
const ROAD_WIDTH = 400;
const TRAFFIC_SPAWN_RATE = 0.02;

// Difficulty settings
DIFFICULTY_SETTINGS = {
    0: { trafficDensity: 1, trafficSpeed: 8 },
    1: { trafficDensity: 1.5, trafficSpeed: 10 },
    2: { trafficDensity: 2, trafficSpeed: 12 }
};
```
